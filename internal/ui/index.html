填写你有使用权限的 Tunnel ID。打开 OpenAI Platform 的 Tunnels 页面 ↗
请创建 Restricted Runtime API Key，只授予目标 Tunnel 的 Tunnels Read + Use 权限；不要使用管理员密钥。打开 API Keys 页面 ↗
密钥只用于本机 tunnel-client 连接，不会写入日志。优先保存到系统凭据库；不可用时回退到仅当前账户可读的本机文件。
清除只删除本机密钥，不会撤销 OpenAI Platform 上的 Key。需先停止连接；重新连接前需再次输入。
需要 v0.0.17 或更高版本，并匹配当前系统与架构。若已加入系统 PATH，可保留默认名称 tunnel-client。Nexora 启动时只检查最低版本，不验证客户端签名或下载来源；选择文件只填写路径。
macOS：推荐在终端运行 brew install openai/tools/tunnel-client，然后运行 tunnel-client --version。这是 OpenAI 支持的安装方式；直接下载的 ZIP 尚未公证，可能被 Gatekeeper 阻止，请勿绕过系统安全提示。查看官方安装说明 ↗
Windows/Linux：从 OpenAI 官方发布页下载匹配的系统和架构包；amd64 对应 x86_64，arm64 对应 ARM 设备。按官方验证步骤 ↗核验。
请先确认操作系统和芯片架构，再从 OpenAI 官方发布页获取对应客户端。

在 ChatGPT 中添加 Nexora

Tunnel 就绪后，在 ChatGPT 添加自定义 MCP 服务器，连接类型选“隧道”，并选择相同的 Tunnel。当前预期认证选“无”：本机 MCP 令牌由 tunnel-client 通过静态请求头注入，不要把运行时 API Key 或本机令牌粘贴到 ChatGPT。此认证组合仍需真实端到端验证。

请查看 OpenAI Tunnel 指南与 tunnel-client 请求头说明。
